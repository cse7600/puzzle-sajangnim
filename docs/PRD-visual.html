퍼즐 사장님

영업권 이관 기반 SMB 마케팅 슈퍼앱 — 사장님은 무료로 쓰고, 플랫폼은 매체 대행 수수료로 번다.

v1.0.0 기준일 2026-06-23 스택 · Next.js 14 / TypeScript / Supabase

우리가 돈을 버는 방식은 단 하나로 압축된다 — 사장님이 네이버 광고 영업권을 플랫폼에 이관하면, 플랫폼은 공식 대행사로서 매체사로부터 대행 수수료를 받는다. 사장님은 모든 기능을 무료로 쓴다. 무료 SaaS와 페이백이 유저를 끌어오고, 그 유저가 영업권을 넘기면서 수수료가 돈다.

핵심: 사장님에게 과금하지 않는다. 수익은 매체사가 대행사에 주는 수수료에서 나온다. 그래서 유저를 모을수록(무료) 수익원이 늘어난다.

3 정부지원 사업 전략

플랫폼 DB = 수혜 대상자 풀

소상공인 DB는 그 자체로 자산이다. 가입 단계에서 정부지원 알림 동의를 받아 수혜 대상자 풀을 축적하면, 정부지원 사업 수요조사 시점에 우리가 곧 모수가 된다. 이는 정부와 협력할 때 강력한 협상 레버리지가 된다.

1

사전 모수 확보

앱 가입 시 정부지원 알림 수신 동의 → 업종·지역·규모 데이터를 DB로 축적.

2

수요조사 접수 시스템

정부지원 사업 수요조사 공고 시 앱 내에서 바로 접수. 신청 자격 자동 체크 + 서류 작성 보조.

3

협력 레버리지

축적된 수혜 대상자 풀로 정부·지자체와 협력. 집행 채널이자 데이터 파트너로 포지셔닝.

핵심 논리: 플랫폼 DB = 정부지원 수혜 대상자 풀. 우리가 모수를 쥐고 있으면, 정부지원 사업의 집행 파트너로 들어갈 명분과 협상력이 생긴다.
